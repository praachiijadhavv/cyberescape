📖 How to Play CyberEscape

🎮 Game Mechanics

  • 6 Levels: Progress through cybersecurity challenges
  • Lives: Start with 3 lives. Wrong answers cost 1 life
  • XP Points: Earn points for correct decisions
  • Timer: Complete each level within the time limit
  • Hints: Use hints to help solve challenges

🔐 The Levels

  1. Level 1 - Create a Secure Password - Build a strong password that meets security criteria
  2. Level 2 - Spot the Phishing Email - Identify fake emails trying to steal information
  3. Level 3 - Identify the Fake WhatsApp Message - Detect social engineering in messages
  4. Level 4 - Detect an OTP Scam - Learn to recognize OTP phishing attempts
  5. Level 5 - QR Code / UPI Safety Challenge - Evaluate suspicious payment links
  6. Level 6 - Fake Shopping Website Challenge - Spot counterfeit e-commerce sites

⭐ Scoring System

Correct Answer (Easy) +50 XP
Correct Answer (Normal) +100 XP
Correct Answer (Hard) +150 XP
Time Bonus (Complete in 50% of time) +50 XP

💡 Tips

  • Read each challenge carefully before answering
  • Use hints if you're unsure (no XP penalty)
  • Strong passwords have uppercase, lowercase, numbers, and symbols
  • Watch for common phishing red flags: urgent language, suspicious links, unknown senders
  • Always verify before clicking or sharing information
